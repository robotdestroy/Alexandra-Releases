## What's new

- The thinking sound now starts after **two seconds** of silent thinking or research, instead of ten seconds.
- The same gentle pulse still repeats every five seconds. Volume and sound are unchanged.
- Quick replies under two seconds stay silent. Speech, push-to-talk, Stop and Setup still stop the sound immediately.
- The existing Thinking sound switch remains available in Setup and the right-click menu. Your preference is preserved.

## Install or update

- Download **Alexandra-win-Setup.exe** for a new Windows x64 installation. No separate .NET install is needed.
- Existing installations download updates automatically by default. Restart once the download finishes, or use **right-click > Updates > Check now**.
- Your API key, preferences and commander memory are preserved. No keys or personal data are bundled.
- This remains an unsigned friends beta; Windows may display an Unknown publisher warning. Do not disable Windows security settings.
