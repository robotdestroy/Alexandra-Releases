## Tonight's additions

- **Session journals:** Automatic Markdown recaps of travel, trade, missions and goals. Catch up after time away.
- **Combat answers:** Short, local-data answers about pips, shields, targets and recorded hull condition.
- **After-action reviews:** Ask how the fight went. Get the recorded sequence, damage and rewards.
- **Optional callouts:** Brief shield-loss, low-hull and heat-damage warnings. Cooldowns keep them quiet; disable in Setup.
- **Take a photo:** Saves a game screenshot to Pictures / Alexandra. No image upload or analysis.

## Notes

- Session journals and combat callouts default on. Both can be disabled in Setup.
- Callouts use the selected voice, skip stale/busy moments and stop for push-to-talk. Generating voice clips uses API credit; cached clips are reused for this launch.
- Combat information is limited to journal/Status observations, not continuous hull/shield percentages, ammo or enemy tracking. No flight automation or background screenshots.
- Existing API keys, preferences and bindings are preserved. No keys, personal journals or conversation data are bundled.
- This public-source build uses Windows-provided Segoe UI; the separately supplied preview font is not bundled.
- Verified with offline regression tests and UI checks. Live combat coaching and callouts still need in-game testing.

## Install or update

- New Windows x64 users: download **Alexandra-win-Setup.exe**. No separate .NET installation required.
- Existing installations download updates automatically by default and apply them on restart. To check now: **right-click → Updates → Check now**.
- Unsigned friends beta: Windows may display an Unknown publisher warning. Do not disable Windows security settings.
