## Journals, photos and in-game assistance

- **Built-in journal viewer:** Read formatted Markdown, tables and checklists without a separate app. A Dextra-style header shows session details, with correctly formatted ship names and a cleaner recorded-span label.
- **Find a session:** Search by ship used, system, mission, goal, date or photo caption. Ship searches distinguish ships actually recorded as used from passing mentions. Multi-word searches, Clear, Ctrl+F and Escape are supported.
- **Latest-session shortcut:** Right-click > View most recent session log opens the newest session, including an ongoing one. View session logs opens the full collection.
- **Photo gallery:** Journal photos have thumbnails and a full-size viewer with Previous/Next, zoom and Fit. Copy or Ctrl+C copies the original-resolution image, not a file path.
- **Captioned photos:** Requested photos can include your spoken caption and are linked to the active session with time and location. No automatic photography.
- **Spoken reminders:** Ask for a one-time reminder when docking, arriving in a named system or touching down. Reminders are saved per commander and wait for a quiet moment outside combat.
- **Landing-pad guidance:** Ask where your assigned pad or a numbered pad is. Supported Coriolis, Orbis and Ocellus interiors get short directions; unknown layouts are not guessed.
- **More reliable combat replies:** Routine pip, target and health updates no longer cut off an otherwise relevant answer. Situation reports stay short; major game/session changes still cancel stale replies.
- **Safer personal storage:** Settings, saved keys, memory and journals live outside the install folder. Existing data is migrated without deleting originals; conflicting files are preserved as backups.
- **Folder access fixed:** The journal viewer resolves the real folder even when Windows redirects app storage. Read, refresh, open the folder or save a Markdown copy without changing the source log.

## Privacy and limits

- No API keys, personal settings, commander journals, conversation records or user photos are included in the download or public source.
- Journal browsing, search and photo copying stay local. HTML is not executed and remote images are not downloaded. Review logs before sharing them.
- Reminders use the selected cloud voice and require memory and cloud operation enabled. They do not perform game actions or automatically complete goals.
- No flight automation. Combat and docking guidance depend on the observations available from the game.
- Includes the refreshed one-page guide and Markdown-renderer license notice. Public-source UI uses Windows-provided Segoe UI.

## Install or update

- New Windows x64 users: download **Alexandra-win-Setup.exe**. No separate .NET installation required. Add your own OpenAI API key in Setup.
- Existing installations download updates automatically by default and apply them on restart. To check now: **right-click > Updates > Check now**.
- Unsigned friends beta: Windows may display an Unknown publisher warning. Do not disable Windows security settings.
