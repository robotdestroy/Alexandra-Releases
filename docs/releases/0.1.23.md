## What's new

- Simpler first-run setup: **Microphone → Push to talk → OpenAI API key**, then **Save and start**.
- Marin is the default voice. Minimal mode, Keep on top, Thinking sound, research browser and memory start on for new users. Optional conversation debug logs stay off.
- The onboarding screen explains cloud processing without an extra permission checkbox. Saving starts cloud voice and research.
- Minimal mode, Keep on top and Thinking sound now live only in the right-click menu. Removed their duplicate Settings controls and the onboarding simulation button.
- Optional **Setup → Open Alexandra when Elite starts**: a quiet Windows sign-in helper opens Alexandra when it detects the game. It does not use the microphone, capture images or make AI requests while waiting. Closing Alexandra keeps it closed for that game session.
- Existing preferences, API keys, bindings and commander memory are preserved.
- Updated the included one-page quick-start guide.

## Install or update

- For a new Windows x64 installation, download **Alexandra-win-Setup.exe**. No separate .NET install is needed.
- Existing installations download updates automatically by default. Restart after the download finishes, or use **right-click → Updates → Check now**.
- No API keys or personal data are bundled. Each user supplies a key once.
- This remains an unsigned friends beta. Windows may display an Unknown publisher warning; do not disable Windows security settings.
