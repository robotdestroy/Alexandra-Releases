## Combat and session-journal improvements

- **Current game data:** Correctly orders legacy and modern Elite journal files, preventing old sessions from hiding your current ship and combat activity.
- **Combat answers and callouts:** Uses unchanged cockpit status while the same running game session is verified, rather than treating it as unavailable solely because its timestamp is older. Adds brief overheating warnings alongside shield-loss, low-hull and heat-damage callouts.
- **Open session logs:** New right-click shortcut opens the folder containing your Markdown gameplay journals.
- **Quick session stats:** Nonzero recorded earnings, combat awards, confirmed player kills, completed missions and other activity totals at the top of each summary. Earnings mean credits received, not net profit; award counts are not invented ship-kill totals.
- **Reliable auto-open:** Waits for a ready window instead of assuming a spawned process succeeded. Retries failed launches up to three times. Restores an existing/minimized window once per new Elite session without taking keyboard focus; preserves intentional closing for the rest of that session.
- **Your stated plans:** Captures short, clear first-person gameplay intentions from voice input in the current session log. No special command or debug logging required. Plans stay separate from confirmed game outcomes and long-term saved goals.
- **Community-goal results:** Records reward claims, contribution increases and redeemed combat bonds. Listed bonuses and unredeemed awards are not treated as received credits.
- **Safer history handling:** Preserves saved personal goals and session-log checkpoints while rebuilding journal projections in chronological order.

## Privacy and limits

- Session journals include short gameplay-plan excerpts, not a full conversation archive. Generated locally with no additional AI requests. Disable gameplay journals in Setup to stop capture; existing files remain.
- Game-journal activity can catch up after time away. Spoken plans cannot be recovered from sessions when Alexandra was not listening.
- Combat data remains limited to game-provided observations. No continuous hull/shield percentages, ammo tracking, background screenshots or flight automation. Live combat testing is still recommended.
- Optional debug logs now include combat-data availability and selected callouts to aid troubleshooting. Debug logging remains off by default.
- Existing API keys, preferences and bindings are preserved. No API keys, personal journals, repaired session logs or conversation records are bundled or published.
- Includes an updated one-page guide. Public-source UI uses Windows-provided Segoe UI.

## Install or update

- New Windows x64 users: download **Alexandra-win-Setup.exe**. No separate .NET installation required.
- Existing installations download updates automatically by default and apply them on restart. To check now: **right-click > Updates > Check now**.
- Unsigned friends beta: Windows may display an Unknown publisher warning. Do not disable Windows security settings.
