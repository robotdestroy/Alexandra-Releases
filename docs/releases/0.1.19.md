## What's new

- Alexandra remembers its window position between launches in both normal and Minimal mode. Move it where you want; no Setup save is needed.
- Window placement recovers onto an available screen if your monitor layout changes.
- Preview voices in Setup with a short spoken greeting. Marin is the default for new profiles; existing saved voice choices are preserved.
- Save stays visible at the bottom of Setup while you scroll or resize. Setting changes still require Save.
- Improved long-session reliability: old game-data tool results no longer accumulate indefinitely in the live voice conversation. Saved commander memory is unchanged.
- Temporary voice rate limits get a bounded retry. Minimal mode shows cooldown/error notices, with a quiet final-error cue when Thinking sound is enabled. No different fallback voice is used.
- Refreshed the included one-page Read Me.

## Install or update

- New testers: download **Alexandra-win-Setup.exe**. Windows x64; no separate .NET install.
- Existing installed copies: automatic downloads are on by default. Restart after the download finishes, or use **right-click > Updates > Check now**.
- One-time setup: enter a separately supplied OpenAI API key, choose your microphone and push-to-talk control, and review cloud consent. Voice previews use a small amount of API credit.
- Your existing key, preferences and commander memory are preserved. No API keys, personal settings, conversations, commander journals or memories are bundled.
- This is an unsigned friends beta. Windows may show an Unknown publisher warning. Do not disable Windows security settings.
