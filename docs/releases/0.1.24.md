## What's new

- Shorter spoken answers: no routine explanations about Inara data reliability or community reporting.
- No unsolicited copy-and-paste tutorials. Successful actions receive brief confirmations such as "Copied Sol" or "Paste sent."
- Specific missing information, conflicting evidence and action failures are still explained when they affect the answer.
- Source checks, destination validation and paste safeguards remain unchanged.
- Existing API keys, preferences, bindings and commander memory are preserved.

## Install or update

- New Windows x64 users: download **Alexandra-win-Setup.exe**. No separate .NET installation is needed.
- Existing installations download updates automatically by default. Restart after the download finishes, or use **right-click → Updates → Check now**.
- No API keys or personal data are bundled. Each user supplies a key once.
- This remains an unsigned friends beta. Windows may display an Unknown publisher warning; do not disable Windows security settings.
