## What's new

- Persistent commander memory: goals, notes, preferences, visited systems, mission progress and recorded construction needs.
- Catch-up from local journals after sessions played with Alexandra closed.
- On-demand carrier records, stored ships, installed/stored modules and engineering details.
- On-demand station catalogs and on-foot inventory when the game has recorded them.
- Say **"Paste that"** after Alexandra copies a system. Keep Elite in front, open the Galaxy Map and select its search field. Ctrl+V only; you submit the search and plot the route.
- A short, bullet-heavy **Read Me**, included with the app and attached below as PDF and Markdown.

## Install or update

- New testers: download **Alexandra-win-Setup.exe**. Windows x64; no separate .NET install.
- Existing installed copies: automatic downloads are on by default. Restart after the download finishes, or use **right-click > Updates > Check now**.
- One-time setup: enter a separately supplied OpenAI API key, choose your microphone and push-to-talk control, and review cloud consent.
- No API keys, personal settings, conversations, commander journals or memories are bundled.
- This is an unsigned friends beta. Windows may show an Unknown publisher warning. Do not disable Windows security settings.
