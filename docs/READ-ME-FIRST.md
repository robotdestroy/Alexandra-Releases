# Alexandra

Voice companion for Elite Dangerous | Windows friends beta 0.1.27

## Get started

- Install Alexandra. No separate .NET install needed.
- Choose microphone, keyboard/HOTAS push to talk and API key. Review cloud processing, then Save and start.
- Hold to speak. Release to hear the answer. Press again to interrupt. No wake word or command prefix.

## Ask about your game

- Your ship, modules, cargo, route, missions, materials and recorded construction needs.
- Carrier location, fuel and jump plans; stored ships and modules.
- Nearby commodities, stations, engineers and material traders; public Inara, Frontier and Reddit research.
- Ask follow-ups naturally. "Where is my pad?" gives directions for mapped starport interiors.

## Remember what matters

- Save goals, notes and preferences. Ask "What was I working on?" or "Forget that note."
- Local journals track plans, CG progress, travel, trades, missions and combat, with relevant quick stats.
- Right-click > View most recent session log. Search by ship or keyword; browse/copy photos or save Markdown. Logs catch up after time away.
- "When I dock, remind me to claim my rewards." Reminders also support system arrival and touchdown; they wait until quiet and out of combat.

## Combat companion

- "Check my pips" or "What's my target?" gets a short answer from local game data.
- "How did that fight go?" reviews recorded damage, rewards and losses.
- Optional shield, hull and heat callouts skip busy moments. Disable in Setup. Voice clips use API credit, then are cached for this launch.

## See the game and copy destinations

- "Take a photo" saves a PNG in Pictures > Alexandra and links it to your journal. Add a spoken caption.
- "Explain this panel" inspects the visible game and answers aloud. Keep Elite in front.
- Copy one verified system name: "Copy that system." Station names are spoken separately.
- "Paste that" sends Ctrl+V with Elite in front and Galaxy Map search selected. You submit and plot.

## Make it yours

- Right-click for Minimal mode, Keep on top and Thinking sound. Window position and size are remembered.
- Setup changes voice/input and preferences. Marin is the default. Optionally open Alexandra when Elite starts.
- Automatic updates are on by default. Downloaded updates apply on the next launch.

## Good to know

- Internet and paid OpenAI API access required. No API key is included.
- Push-to-talk records your voice. Cloud processing sends voice, relevant game data and requested analysis images to OpenAI.
- Memory and session journals stay local; relevant memories can accompany questions. Review logs before sharing. Debug logs default off.
- Records may be old or incomplete. No live shield percentage/ammo, private Inara access or automatic flying.
- Unsigned beta: Windows may show Unknown publisher. Use the official download below; don't disable Windows security.
