# Alexandra

Voice companion for Elite Dangerous | Windows friends beta 0.1.24

## Get started

- Install Alexandra. No separate .NET install needed.
- First launch: choose your microphone, set keyboard or HOTAS push to talk, and add your API key. Review the cloud-processing note, then choose Save and start.
- Hold to speak. Release to hear the answer. Press again to interrupt. No wake word or command prefix.

## Ask about your game

- Your ship, cargo, current location, route and active missions.
- Engineering materials, unlocks and recorded construction requirements.
- Your carrier's last-recorded location, fuel and jump plans.
- Installed modules, engineering, stored modules and stored ships.
- Nearby commodities, stations, engineers and material traders.
- Game mechanics, community goals and advice from public Inara, Frontier, Reddit and other sources.
- Ask follow-ups naturally: "Is there a closer option?" or "Give me the short version."

## Remember what matters

- Save goals, notes, places and preferences across launches.
- Catch up from available game journals, including sessions played with Alexandra closed.
- Try: "Remember this as my mining spot," "What was I working on?" or "Forget that note."

## See the game and copy destinations

- "Take a screenshot" saves a PNG in Pictures > Alexandra.
- "Explain this panel" inspects the visible game and answers aloud. Keep Elite in front.
- Copy one verified system name: "Copy that system." Station names are spoken separately.
- "Paste that" sends Ctrl+V with Elite in front, the Galaxy Map open and its search field selected. You still submit the search and plot the route.

## Make it yours

- Minimal mode, Keep on top and Thinking sound start on. Change them in the right-click menu. Drag or resize the overlay; position and size are remembered.
- Right-click > Setup for voice input and other preferences. Marin is the default voice. Optionally enable Open Alexandra when Elite starts.
- Automatic updates are on by default. Downloaded updates apply on the next launch.

## Good to know

- Internet and paid OpenAI API access required. No API key is included.
- The microphone records only while push-to-talk is held. Save and start enables voice, relevant game data and visual-question images to be sent to OpenAI.
- Memory is stored locally; relevant memories can accompany AI requests. Optional local conversation debug logs are off by default.
- Records and market listings can be old or incomplete. No private Inara account access, guaranteed live stock or automatic flying.
- Unsigned test build: Windows may show an Unknown publisher warning. Use only the official download below.
